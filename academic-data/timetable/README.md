# Official timetable intake

Place the department-approved current class and lab timetable here. Do not
replace an older term. Record the file in `source-registry/source_inventory.csv`
with its effective semester, checksum, verifier, and expiry date.

Required fields: semester, course_code, section, instructor_or_ta, day,
start_time, end_time, room_or_lab, and source_id.
